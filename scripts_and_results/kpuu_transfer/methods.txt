Cross-endpoint transfer was evaluated in 43 independent structures with exact positive rat Kp,uu measurements, with repeated measurements summarized by the median on the log10 scale. Compounds matching any member of the full supplied BBB development dataset were excluded using RDKit parent-fragment standardization, uncharging, removal of stereochemistry, and the HetAtomTautomerv2 hash for tautomer-insensitive matching. Required descriptors were computed by name using Mordred, radius-2 2048-bit Morgan fingerprints without chirality, and 167-bit MACCS keys, retaining only features needed by the saved models and their preprocessing. Three-dimensional coordinates were generated with the same seeded OpenChemLib procedure as notebook 01, using the DataWarrior/OpenChemLib JAR recorded in the run metadata. The first conformer from low-energy-biased systematic generation with crystallographic torsions (maximum 1,000 torsion sets) was minimized with MMFF94s+ (dielectric constant 1; maximum 10,000 iterations; gradient tolerance 0.0001; function tolerance 1e-6). Seeds were derived from base seed 20260915 and the original SMILES using the notebook SHA256 scheme. As in notebook 01, conformers were retained if minimization failed, with failures recorded, centered, and exported as V3000 SDF. Mordred descriptors were calculated using the same python -m mordred -3 command; ECFP4 and MACCS fingerprints were calculated from the original input SMILES. Existing BBB regressors were applied with their saved preprocessing, without retraining, recalibration, or Kp,uu-based model or threshold selection. Saved outer-fold predictions were averaged to give one prediction per model per compound. Transfer was assessed primarily by Spearman correlation between predicted logBB and log10(Kp,uu), with Pearson correlation and Kendall tau-b reported as additional association measures. Paired resampling of compounds (2000 bootstrap samples) provided percentile 95% confidence intervals for metrics and all pairwise between-model differences, conditional on the fitted models and saved thresholds. Numerical logBB errors were not calculated against Kp,uu because these represent different endpoints.
